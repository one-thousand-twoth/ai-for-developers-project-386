# Календарь звонков — фронтенд

Минимальное приложение на React, TypeScript и Vite. Зависимости устанавливаются через pnpm.
Node.js и pnpm управляются через mise в корне репозитория.

Из корня проекта:

```bash
mise install
mise run web:install
mise run web:dev
```

Проверки: `mise run web:build` и `mise run web:lint`.
Готовая сборка находится в `web/dist/`.
